# StockGen

* Python version - 3.12.0
* Django version - 5.1.7
* Virtualenv - https://pypi.org/project/pipenv/

## How to run the project locally

* Clone this project and enter `django-task`
* Install `pip install pipenv` 
* Create a new virtualenv `pipenv install`
* Activate the virtualenv `pipenv shell`
* Type `python manage.py runserver` and visit `localhost:8000` in browser
